## Amendment 3, 2026-11-13 17:15 UTC, after the whole ladder had been read

Amendment 2's rule said "first order if s <= 1.3", with no lower bound on s, so a flat series would be called first order. The ladder is flat (slope -0.11, below), which the letter of the rule would call "first order". That is a defect of my rule, not a result: a first-order error is |F| proportional to a (s about 1). I read "flat" as its own class, s < 0.7, and `table_682.py` (with its selftest, which now includes a flat series that must come out FLAT) prints both readings. The class "FLAT" says the quad-double |F| of the prediction shows no a-dependence at all above the floor's noise, which excludes a first-order and a second-order error at the resolution of the floor.
