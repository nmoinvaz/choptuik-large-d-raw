The points are D 21.3125, 21.375, 21.4375 and 21.5 if no step halves (a failed solve halves h; the grid is then finer).
**Stops** (t5's): the guard's fold rule (`leap_guard.py`: dDelta/dD changes sign or is zero; max cos_t_reg >= 0.5; n_null rises with cos >= 0.3), the leap's own constraint bar (--cmax 1e-2) and --fmax, an exception (a Traceback in `leap.log`, or a non-zero exit), a point over 3 h (a watchdog of mine, `leg_watch.py`, kills by the same exact-pid function of the guard). Memory: the peak RSS of the first point is reported; nothing is killed for memory.
**Per point:** the state and the record go to this folder and to raw; then the lambda_1 scan (`../kc87_leg_lambda/pipeline87.sh`'s steps, parametrized for this folder: source check with controls, 6 evaluations on 2 processes at nice 15), and the tracker row (`mode_tracker.py` on the chain: dh370's record, then this leg's) is reported.
