# harmony-mac: outputs of the cross-field pilots of 2026-11-07

Machine: the coordinator's Mac (Apple M5). The scripts are in the main repository's `solver/harmony/<field>/`; the summary
is notes/HARMONY.md. One folder per field: brownian, dss_explosions, implosion, larson_penston, magnetism, stokes. Each
holds the logs and JSON or text outputs its scripts wrote, flattened from the scratch folders they ran in. Downloaded
papers and their extracted text were left out.
