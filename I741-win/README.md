## Plan, written before the runs (2026-11-14 01:23 UTC)

1. **The edit** (`make_shifts_741.py`, the data edit of #727's `make_states_727.py`): copies of cont3's state in `states/`, with the node `segs[3][1]` (0.6485815917372736, the first free interior node of the last segment, where X2's plan differs most from cont3's, by 9.489e-4) moved by 0 (S0, the control), 1e-4 (S1), 3e-4 (S2), 1e-3 (S3), 3e-3 (S4), and 1e-2 (S5, made now but run only after the fit is written down). Only `meta["segs"]` changes, by exactly that node; the arrays are bit-identical; the originals are untouched (`states/edit_log.txt`; `--selftest` flags a planted array change, a second meta key, two nodes, the wrong node, the wrong shift and a missing shift). The segment's second interior node is the midpoint of the first and the segment end in the stored plans; I move the first only and leave the second, because the solver takes the nodes as given (`segs` is used as stored). If a polish rejects the plan, I report that.
2. **The unshifted root** is X2c's Delta (`I727-win/X2c`, the octo-double root of cont3's plan, max|F| 2.7e-93): every Delta shift is read against it.
3. **(a)** each polish converges to octo-double max|F| of at most 1e-60 (the corrector's own "converged").
4. **(c) the control** S0 (the plan unshifted) reproduces X2c's Delta to 1e-40. S0 starts at cont3's stored quad-double state, which sits 1.1101e-46 off the root in Delta (#727's pilot2: its polish took no Newton step), so S0 meets the bar of 1e-40 but trivially, and the shifted runs, which take real Newton steps, are the test of the polish.
5. **(b) the fit**: ordinary least squares of log10 |Delta_s - Delta_root| on log10 s over S1 to S4 (4 points; `fit_741.py`), reporting the exponent p, the coefficient and the per-point residuals in log10 (rms and max). All four shifts must have the same sign, else it is not a power law. The prediction for s = 1e-2 is written to `fit_741_out.txt` **before S5 runs** (`run_741.py S5` refuses without that file, and `fit_741.py --check5` refuses unless the fit file is older than S5's state), and S5 passes if the prediction is within 10 % of the measured shift. `fit_741.py --selftest` plants a power law (recovered), a sign change (flagged) and a law with equal linear and quadratic terms at s = 3e-3 (misses by 47 %, so the 10 % bar can fail).

**Expectation, written before the runs and not a criterion**: from #727, a plan whose nodes differ by 5e-4 to 1e-3 gave Delta offsets of 3e-26 to 1.7e-25, so I expect the shift of a single node by 1e-3 to give 1e-27 to 1e-25, an exponent between 1 and 2 (linear if cont3's plan is not stationary for Delta, about 2 if it is), and 5 to 7 minutes a point at 4 threads, so about 40 minutes for S0 to S4 and 7 for S5.
