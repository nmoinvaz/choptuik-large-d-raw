Acceptance 1 (the control): each of the first 12 bounds of each run reproduces #681's log (`I681-win/logs/K7_D40_rough.log`, `K0_D40_rough.log`) to |a - b| / b <= 1e-3 against #681's printed value (4 significant digits, so printing alone is up to 5e-4), each start as it appears. 4. Acceptance 2: R_a(48) = median(K 7, 48) / median(K 0, 48), the median of a run being the geometric mean of its 24th and 25th smallest bounds, with the 95% bootstrap interval (10000 resamples of each run's 48 bounds with replacement, `random.Random(701)`, the 2.5th and 97.5th percentiles of R_a), judged against [1/3, 3] by #701's rule (`table_701.verdict`, imported, not copied): HOLDS if the point and the interval lie inside, FAILS if the point is outside and the interval lies entirely outside, UNDECIDED otherwise. The 12-start value from the first 12 of each run is printed beside it (#681: 0.98).
5. Acceptance 3: R_a(48) / R_b(48) with its 95% bootstrap interval, judged against 1. The interval comes from one joint bootstrap: 10000 resamples with `random.Random(701)`, each drawing in this order a run's K 7, a run's K 0, b run's K 7, b run's K 0 (48 draws with replacement each, from that run's 48 bounds), the ratio (median a7 / median a0) / (median b7 / median b0), and the 2.5th and 97.5th percentiles.
